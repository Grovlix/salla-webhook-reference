# Assets Directory / دليل الأصول

This directory contains images and assets used in the documentation.

يحتوي هذا الدليل على الصور والأصول المستخدمة في التوثيق.

## Files / الملفات

| File | Purpose |
|------|---------|
| `logo.svg` | Main logo for the documentation site / الشعار الرئيسي لموقع التوثيق |
| `logo.png` | PNG version of the logo / نسخة PNG من الشعار |
| `og-image.png` | Open Graph image for social sharing / صورة Open Graph للمشاركة الاجتماعية |
| `twitter-image.png` | Twitter card image / صورة بطاقة Twitter |
| `favicon.ico` | Favicon for the browser / أيقونة المتصفح |

## Usage / الاستخدام

### In Markdown / في Markdown

```markdown
![Logo](/assets/logo.png)
```

### In Vue Components / في مكونات Vue

```vue
<img src="/assets/logo.svg" alt="Salla & Zid Webhook Reference">
```

## SEO / تحسين محركات البحث

The following meta tags reference these assets:
تستخدم وسوم الميتا التالية هذه الأصول:

- Open Graph image: `/assets/og-image.png`
- Twitter card image: `/assets/twitter-image.png`
- Favicon: `/assets/favicon.ico`

## Dimensions / الأبعاد

- **Logo SVG**: 200x200px
- **Logo PNG**: 512x512px
- **OG Image**: 1200x630px (recommended for Open Graph)
- **Twitter Image**: 1200x600px (recommended for Twitter cards)
- **Favicon**: 32x32px, 16x16px
