# Zid: Customer events

<p dir="rtl" lang="ar">أحداث العملاء في زد</p>

| Event | Description | الوصف |
| --- | --- | --- |
| [`customer.create`](./customer.create.md) | Triggered when a new customer account is created. | يُرسل عند إنشاء حساب عميل جديد. |
| [`customer.update`](./customer.update.md) | Triggered when a customer's details are updated. | يُرسل عند تحديث بيانات عميل. |
| [`customer.merchant.update`](./customer.merchant.update.md) | Triggered when the merchant updates details related to a customer. | يُرسل عندما يعدّل التاجر بيانات متعلقة بالعميل. |
| [`customer.login`](./customer.login.md) | Triggered when a customer logs in. | يُرسل عند تسجيل دخول العميل. |

Official page: [docs.zid.sa/webhook-events-customer](https://docs.zid.sa/webhook-events-customer)
