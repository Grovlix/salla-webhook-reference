# Zid: Product events

<p dir="rtl" lang="ar">أحداث المنتجات في زد</p>

| Event | Description | الوصف |
| --- | --- | --- |
| [`product.create`](./product.create.md) | Triggered when a new product is created. | يُرسل عند إضافة منتج جديد. |
| [`product.update`](./product.update.md) | Triggered when a product's details are updated. | يُرسل عند تحديث بيانات منتج. |
| [`product.publish`](./product.publish.md) | Triggered when a product is published. | يُرسل عند نشر منتج. |
| [`product.delete`](./product.delete.md) | Triggered when a product is deleted. | يُرسل عند حذف منتج. |

Official page: [docs.zid.sa/webhook-events-product](https://docs.zid.sa/webhook-events-product)
