# Salla: Shipping company and zone events

<p dir="rtl" lang="ar">أحداث شركات ومناطق الشحن في سلة</p>

| Event | Description | الوصف |
| --- | --- | --- |
| [`shipping.zone.created`](./shipping.zone.created.md) | Triggered when a shipping zone is created for a custom shipping company. | يُرسل عند إنشاء منطقة شحن لشركة شحن مخصّصة. |
| [`shipping.zone.updated`](./shipping.zone.updated.md) | Triggered when a shipping zone is updated for a custom shipping company. | يُرسل عند تحديث منطقة شحن لشركة شحن مخصّصة. |
| [`shipping.company.created`](./shipping.company.created.md) | Triggered when a custom shipping company is created. | يُرسل عند إنشاء شركة شحن مخصّصة. |
| [`shipping.company.updated`](./shipping.company.updated.md) | Triggered when a custom shipping company is updated. | يُرسل عند تحديث شركة شحن مخصّصة. |
| [`shipping.company.deleted`](./shipping.company.deleted.md) | Triggered when a custom shipping company is deleted. | يُرسل عند حذف شركة شحن مخصّصة. |

Official page: [docs.salla.dev/webhook-events/shippings](https://docs.salla.dev/webhook-events/shippings)
