# Salla: Store events

<p dir="rtl" lang="ar">أحداث المتجر في سلة</p>

| Event | Description | الوصف |
| --- | --- | --- |
| [`store.branch.created`](./store.branch.created.md) | Triggered when a store branch is created. | يُرسل عند إنشاء فرع للمتجر. |
| [`store.branch.updated`](./store.branch.updated.md) | Triggered when a store branch is updated. | يُرسل عند تحديث فرع للمتجر. |
| [`store.branch.setDefault`](./store.branch.setDefault.md) | Triggered when a store branch is set as the default branch. | يُرسل عند تعيين فرع كفرع افتراضي. |
| [`store.branch.activated`](./store.branch.activated.md) | Triggered when a store branch is activated. | يُرسل عند تفعيل فرع للمتجر. |
| [`store.branch.deleted`](./store.branch.deleted.md) | Triggered when a store branch is deleted. | يُرسل عند حذف فرع للمتجر. |
| [`storetax.created`](./storetax.created.md) | Triggered when a store tax is created. | يُرسل عند إنشاء ضريبة للمتجر. |
| [`store.owner.changed`](./store.owner.changed.md) | Triggered when store ownership moves to another user. | يُرسل عند نقل ملكية المتجر إلى مستخدم آخر. |

Official page: [docs.salla.dev/webhook-events/store](https://docs.salla.dev/webhook-events/store)
