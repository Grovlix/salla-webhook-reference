# Salla: Shipment events

<p dir="rtl" lang="ar">أحداث الشحنات في سلة</p>

| Event | Description | الوصف |
| --- | --- | --- |
| [`shipment.creating`](./shipment.creating.md) | Triggered when a shipment is assigned to a shipping company. | يُرسل عند إسناد شحنة إلى شركة شحن. |
| [`shipment.created`](./shipment.created.md) | Triggered when the shipping company updates a shipment for the first time. | يُرسل عندما تحدّث شركة الشحن الشحنة لأول مرة. |
| [`shipment.updated`](./shipment.updated.md) | Triggered when a shipment is updated after creation. | يُرسل عند تحديث الشحنة بعد إنشائها. |
| [`shipment.cancelled`](./shipment.cancelled.md) | Triggered when a shipment is cancelled. | يُرسل عند إلغاء شحنة. |

Official page: [docs.salla.dev/webhook-events/shipments](https://docs.salla.dev/webhook-events/shipments)
