# Salla: Customer events

<p dir="rtl" lang="ar">أحداث العملاء في سلة</p>

| Event | Description | الوصف |
| --- | --- | --- |
| [`customer.created`](./customer.created.md) | Triggered when a customer is created. | يُرسل عند تسجيل عميل جديد. |
| [`customer.updated`](./customer.updated.md) | Triggered when a customer is updated. | يُرسل عند تحديث بيانات عميل. |
| [`customer.login`](./customer.login.md) | Triggered when a customer logs in to their account. | يُرسل عند تسجيل دخول العميل إلى حسابه. |
| [`customer.otp.request`](./customer.otp.request.md) | Triggered when a customer requests a one-time password. | يُرسل عند طلب العميل رمز تحقق لمرة واحدة (OTP). |

Official page: [docs.salla.dev/webhook-events/customers](https://docs.salla.dev/webhook-events/customers)
