## Fields

Fields marked * are required in the official schema.

| Field | Type | Description |
| --- | --- | --- |
| `event` | string | The webhook topic that fired. Determines whether the payload relates to an outgoing SMS or email. One of: `communication.sms.send`, `communication.email.send`, `communication.whatsapp.send`. |
| `merchant` | number | Merchant ID of the store that triggered the webhook. Use this ID to look up the merchant’s details via the documented endpoint [here](https://docs.salla.dev/9466620e0). |
| `created_at` | string | Time the webhook was generated by Salla (server time). |
| `data` | object |  |

### `data`

| Field | Type | Description |
| --- | --- | --- |
| `notifiable` | array of string | Target recipients for the message: phone numbers for SMS or email addresses for email. Maximum 500 campaign sms notifiable are allowed. |
| `type` | string | Business event for which the message was sent (see enum for the full catalog). |
| `content` | string | Rendered message body. For order-related emails, this may be empty (content is often contained in the email template itself). |
| `entity` | object \| null | Context object for the event’s primary entity (may be null if not applicable). |
| `meta` * | object \| null | A key-value map of additional metadata related to the notification. Useful for providing extended context or computed details that are not included in the entity field. |
